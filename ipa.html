El Alfabeto Fonético Internacional (IPA) representa exactamente cómo se pronuncia cada sonido. Tocá cualquier símbolo para escucharlo, o tocá las palabras de ejemplo para escucharlas completas.
Cómo usar esta guía Tocá el círculo ▶ para escuchar el fonema aislado. Tocá las palabras en gris para escuchar el ejemplo completo. El sonido resaltado muestra dónde aparece el fonema.
